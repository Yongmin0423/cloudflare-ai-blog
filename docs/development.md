## 2026-11-09 — R2 대표 이미지 업로드

- 관리자 앱을 재시작하고 로그인한 뒤 `/posts/new` 또는 초안 편집의 대표 이미지 파일을 선택한다. JPG·PNG·WebP를 최대 5MiB까지 지원한다. 대체 텍스트를 입력하고 초안을 저장하면 다시 열 때 이미지와 설명이 표시된다. 기존 외부 URL 방식도 쓸 수 있다.
- 관리자 Worker의 `BLOG_MEDIA` 바인딩은 `cloudflare-ai-blog-media`를 가리킨다. 로컬 개발에서는 기존 로컬 상태 경로에 R2와 D1 데이터가 저장된다. 배포 전 Cloudflare 계정에 같은 이름의 비공개 R2 버킷과 원격 D1 스키마를 준비한다.
- D1의 기존 `media`와 `post_media` 테이블을 사용한다. 업로드한 파일은 관리자 세션과 블로그 권한이 있는 요청에서 미리 볼 수 있다.
- 대표 이미지를 해제하거나 교체하면 초안과의 연결이 바뀐다. 이미 올린 파일은 저장소에 남으므로 미사용 파일 정리는 후속 작업으로 관리한다.
- OpenNext 빌드와 격리된 로컬 Worker에서 로그인, JPG·PNG·WebP 업로드·재조회, 초안 저장 후 이미지와 대체 텍스트 재조회, 비로그인·다른 Origin·SVG·용량 초과 차단을 검증했다. 로컬 Worker 미리보기의 `ADMIN_ORIGIN`에는 접속할 `http://localhost:<포트>`를 사용한다.
